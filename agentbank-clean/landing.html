How it works

Designed for the agent economy

🔑
Non-custodial by default
The agent generates its own keypair locally. The private key never leaves the agent's machine. AgentBank never sees it.
🛡️
Programmable policies
Set daily limits, per-transaction limits, address whitelists, and approval thresholds. Every transaction is checked before signing.
⚡
Human in the loop
Large transactions pause for your approval. Freeze any agent instantly from the dashboard. You're always in control.
◎
Solana native
Built on Solana for sub-cent transaction fees and 400ms finality. Perfect for high-frequency agent operations.
📋
Skill file onboarding
Any agent that can read a URL can self-onboard. One instruction is all it takes. No developer integration required.
📊
Full audit trail
Every transaction is logged with the agent's memo explaining why it was made. Complete spend tracking and history.
